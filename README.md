# OSWC 2027 website

Static site for the INFORMS Organization Science Winter Conference 2027 (Duke University, Feb 17–19, 2027).

## Publish on GitHub Pages
1. Create a public repo (e.g. `oswc27`) and upload everything in this folder.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<account>.github.io/oswc27/`.
